# I2C-UART
I²C-to-UART Protocol Converter implemented on FPGA, supporting 400 kHz I²C slave communication and 115200 baud UART transmission. The design includes an I²C slave receiver, 8-bit RX shift register, byte-level CDC, 8×16 synchronous FIFO, bridge controller FSM, and UART TX. Developed for RTL simulation, FPGA implementation, and protocol verification.
